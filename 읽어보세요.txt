  AGI 아기 — 읽어보세요
  (사전을 통째로 주입하지 않고, 백지에서 겪어서 배우는 아기)
════════════════════════════════════════════════════════════

■ 이게 뭐야
  사람 아기처럼, 아무것도 모르는 백지에서 시작해서
  세상을 겪으며 스스로 배우는 프로그램. AI(정답 주입)가 아니라,
  보고·듣고·이름 알아내고·여러 번 겪어서 아는 방식.

■ 돌리는 법
  1) 파이썬 3.10+ 설치
  2) 처음 한 번만 — 명령창(cmd)에서 이 폴더로 이동 후:
       윈도우:  설치_윈도우.bat  실행
       맥/리눅스: bash 설치_맥리눅스.sh
     (이게 Pillow·numpy·kollocate·playwright·크로미움 등을 깐다)
  3) python server.py   →  브라우저에서 http://localhost:8000
     * 처음 켤 때 사전 받느라 20~30초. 화면 뜰 때까지 기다려라.
       (dict_cache 폴더에 저장되면 다음부턴 빠름)

  ★ 브라우저 검색이 안 되면(오른쪽 패널이 "브라우저 못 켰어요"라고 하면),
    명령창에서 이거 한 번 실행:
       python -m playwright install chromium
    이게 아기가 쓸 브라우저 본체(크로미움)를 까는 것.
    안 깔면 아기가 인터넷 검색을 못 한다.

■ 화면 보는 법
  왼쪽: 성장 단계 (1 유아기 ~ 8 마음·사회, 9 자동 성장)
  가운데: 지금 단계 내용, "자동 성장 시작" 버튼, 말 걸기
  오른쪽 패널(🌐): 아기가 지금 뭘 하는지 실황 로그 +
                   아기가 쓰는 브라우저 실제 화면(스크린샷)
                   (닫으면 오른쪽 위 "🌐 브라우저 열기")

■ 어떻게 배우나 (핵심 — 사전 주입이 아님)
  · 태어날 때 아는 단어 = 0개 (백지)
  · 살아가며 사물을 만나면:
      - 진짜로 봄(인터넷 이미지) → 시각 특징을 뽑음
      - 이름을 알아냄(걸음마는 사전, 그다음은 검색)
      - [본 특징 + 들은 이름]을 스스로 연결
      - 같은 걸 여러 번(3번+) 겪어야 "확실히 안다"
  · 아기는 스스로 궁금해한다 — 눈앞에 보이는데 모르는 것을
    "이게 뭐지?" 하고 궁금증에 담아, 자동으로 찾아본다.
    (사람이 단어를 알려줄 필요 없음. 알아서 세상을 둘러본다)
  · 세상 = 인터넷. 사전은 걸음마용 시작점일 뿐.

■ 잘못된 정보를 안 삼키게 (계속 겪어서 걸러냄)
  · 인터넷엔 광고·틀린 글·페이월이 섞여 있다. 그냥 읽고 다 믿지 않는다.
  · 정답표로 맞다/틀리다를 대조하지 않는다(그건 LLM 방식). 사람 아기처럼:
      - 같은 것을 여러 출처에서 겪을수록 '더 확실해 보인다'(확정은 아님).
      - 관계마다 '증거'를 다 저장한다(본 횟수·반대 본 횟수·어느 사이트에서 봤나).
        확신도는 저장하는 게 아니라 볼 때마다 다시 계산한다. 고정 임계값 없음.
      - '몇 곳이 말한다'가 '사실이다'는 아니다. 가짜뉴스 여러 곳도 여기선 그냥
        증거량일 뿐. 그래서 반대 증거가 나오면 언제든 흔들리고 뒤집힌다.
      - 이미 믿던 것과 어긋나는 정보를 만나면 바로 안 믿고 '의심'에 올린다.
        반대 증거가 쌓이면 '지금 믿는 것'이 바뀐다(예: 펭귄을 어류로 알았다가,
        조류라는 증거가 더 쌓이면 조류로 뒤집힘). 확정 상태를 만들지 않는다.
      - 이 확신도는 화면 6단계 관계망에 [확신 N] 숫자로 보인다.

■ 아기가 찾는 방법 = 사람처럼
  · 진짜 브라우저 창을 띄워서, 검색창에 치고,
    사람처럼 마우스 움직이고 스크롤하며, 사이트를 '한 개씩 순서대로' 열어 읽는다.
    (동시에 여러 개를 긁지 않는다 = 봇 아님. 사람은 눈이 하나라 한 화면씩 본다)
  · 위키 API로 몰래 긁는 봇 방식이 아니다.
  · 여러 검색엔진(구글·빙·덕덕고·네이버) 결과를 '전부 합친다'(한 곳에서 안 멈춤,
    중복 주소 제거). 한 번에 최대 20곳까지 열어 여러 출처를 합쳐 조사한다.
  · 브라우저는 '딱 한 번만' 켜고 그 안에서 탭을 하나씩 바꾼다
    (사이트마다 껐다 켜지 않음 = 느림 제거). 그래서 '사람 방식은 지키되 빠르게'.
    봇으로 걸리는 요소(위장 UA·자동화표시 숨김·비headless·locale)는 유지하고,
    봇 감지와 무관한 굼뜬 대기만 줄였다(browser_search.py 의 SPEED 값).
  · (봇차단 대응 추가) 쿠키/동의 배너가 막고 있으면 사람처럼 '동의/수락'
    버튼을 눌러 닫는다. 검색 결과가 실제로 떴는지도 보고, 안 떴으면
    "⚠️ 캡차/동의 화면일 수 있음"으로 정직히 알리고 그 화면을 패널에 남긴다.
    멈춤 시간도 사람처럼 들쭉날쭉하게(가끔 길게) 했고, 결과를 잘 주는
    검색엔진부터 먼저 가고 0건인 엔진은 뒤로 미룬다(껐다 켜면 초기화).
    그래도 봇 차단이 완전히 풀린 건 아니다(아래 '한계' 참고).
  · 읽은 것 중 광고·페이월 껍데기(로그인/구독/쿠키동의/결제 등)는
    '내용'이 아니므로 학습 전에 버린다(browser_search.py 의 _is_junk_text).
    정답표가 아니라 '이건 글이 아니라 껍데기'라는 패턴이다.


■ 안전하게 조사 (위험 사이트 거르기)
  · 사이트를 열기 전에 먼저 안전 검사를 한다(safety.py).
    - 위험 파일(.exe·.apk 등), 생 IP 주소, 단축 URL, 의심 도메인 → 안 연다
    - 유튜브는 지금은 조사 안 함(나중에)
    - 네 컴퓨터에선 악성 URL 공개목록(URLhaus)도 받아 대조한다
    - VirusTotal(70여 개 백신)로도 검사한다. 사람처럼 —
      아기가 브라우저로 virustotal.com URL 탭에 가서 주소를 넣고
      결과(악성 몇 개인지)를 읽는다. (API 아님, 돈 안 듦)
      · 정직하게: VT 사이트는 JS가 무겁고 봇 감지가 있어 실패할 수 있다.
        실패하면 API로 넘어간다(config.py VIRUSTOTAL_API_KEY 에 무료 키가
        있을 때. 무료 키: virustotal.com 가입 > 이름 > API key).
      · (개선됨) VT 브라우저 검사도 조사용 브라우저를 '재사용'한다 —
        사이트마다 새 브라우저를 안 켠다. 그래서 VT를 켜도 브라우저는 한 번만 켜진다.
        그래도 느리면 config.py 의 VIRUSTOTAL_ENABLE = False 로 끄면 된다
        (정적 필터는 계속 동작).
  · 걸러낸 건 로그에 "🛡 안전검사: N곳 걸러냄"으로 뜬다.
  · 정직하게: 이건 기본 필터지 완벽한 백신이 아니다.

■ 정직하게 — 지금의 한계
  · 진짜 이미지·소리·검색은 "네 컴퓨터(인터넷 됨)"에서만 진짜로 된다.
  · 검색엔진(구글·네이버 등)이 자동 브라우저를 막을 수 있다
    (동의 화면/캡차). 그러면 검색 결과가 0곳이 되고, 오른쪽 패널에
    "⚠️ 검색 결과를 못 가져왔어요"라고 정직하게 뜬다.
    이건 "사람처럼 검색"의 근본 난관이라, 이번에 대응(배너 자동 닫기·캡차
    의심 표시·지연 다양화·엔진 우선순위)을 넣었어도 완전히 해결되진 않았다.
  · 추상(사랑·시간) 발견은 진짜 이미지가 켜져야 제대로 된다.
  · 실시간 발성(50번)은 기초만 — 답을 문장 조각으로 나눠 순차로 읽는다
    (통째 읽기 아님). 진짜로 자연스럽게 들리는지는 네 컴퓨터에서 확인.
    음성 데이터(목소리)로 말하기는 아직.
  · 화면 글자 읽기(OCR·사람처럼 보기)는 PIL·pytesseract·tesseract 본체가
    있어야 한다. 없으면 이제 패널에 ⚠️로 한 번 알려주고, HTML 본문 읽기로
    대체해 계속 간다(예전엔 조용히 빈손이었음).
  · 정보 신뢰성(여러 출처 교차검증·모순 시 뒤집기, 아래 항목)의 '로직'은 확인됐지만,
    진짜 인터넷에서 20곳을 읽으며 실제로 축적·역전되는 건 네 컴퓨터에서 확인된다.


■ 채팅과 음성 (💬 화면 9단계)
  · 아이에게 물어보면: 배운 건 스스로 답하고, 모르는 건 인터넷을
    검색해서 알려준다(LLM처럼 통째로 아는 척이 아니라 사람처럼).
  · 🎤 마이크로 말하면 음성을 알아듣고, 🔊 답을 소리로 읽어준다 —
    이제 통째가 아니라 문장 조각으로 나눠 차례로 말한다(스트리밍).
    말하는 중에 새로 물으면 이전 발화는 멈춘다.
    (브라우저 기능 사용 — 크롬에서 열어야 마이크가 됨. 외부 서비스/LLM 아님)
