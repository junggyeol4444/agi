  검증 가이드 — 네 컴퓨터에서 뭘 확인하면 되나
  (내 작업 환경은 인터넷이 막혀서, 진짜 작동은 네 컴퓨터에서만 확인됨)
════════════════════════════════════════════════════════════

■ 0. 먼저 브라우저 본체 깔기 (검색 쓰려면 필수)
   명령창(이 폴더)에서:
      python -m playwright install chromium
   안 깔면 아기가 검색을 못 한다(오른쪽 패널이 "브라우저 못 켰어요").

■ 1. 백지에서 시작하나
   - 서버 켜고 화면 위쪽을 봐라.
   - "아는 단어 0개"로 시작해야 맞다(태어날 때 백지).
   - 예전엔 태어나자마자 여러 개 아는 걸로 나왔음 → 고침.

■ 2. 스스로 궁금해하나 (사람이 안 알려줘도)
   - "자동 성장 시작" 누르고 오른쪽 패널 로그를 봐라.
   - 몇 초 안에 "⏳ 궁금: (사물들) — 곧 찾아볼게요" 처럼
     아기가 스스로 궁금해하는 게 떠야 한다.
   - "말을 걸어 주세요" 같은 건 이제 안 나온다(스스로 찾음).

■ 3. 실황 로그가 계속 뜨나
   - 자동 켜면 3초마다 상태 한 줄이 계속 떠야 한다
     (살아가는 중 / 궁금 / 찾아 배움 / 자기평가 등).
   - 껐다 다시 켜도 몇 초 안에 다시 떠야 한다.
   - 만약 "💥 ..." 가 뜨면, 그 문구를 그대로 나에게 보내라(에러 내용).

■ 4. 아기의 브라우저 화면이 뜨나
   - 궁금한 게 생기면 오른쪽 패널 "지금 브라우저"에
     검색하는 실제 화면(스크린샷)이 떠야 한다.
   - 진짜 브라우저 창도 뜬다(SHOW_BROWSER=True).
   - 만약 "⚠️ 검색 결과를 못 가져왔어요"가 뜨면:
     검색엔진이 자동 브라우저를 막은 것. 패널 화면에 캡차/동의
     화면이 보이는지 확인하고, 그 화면을 캡처해서 나에게 보내라.

■ 5. 진짜 이미지로 배우나 (추상 발견의 근거)
   - config.py 의 USE_REAL_IMAGE 가 True 여야 진짜 이미지를 본다.
   - 사과 같은 건 이미지가 일정 → 구체. 사랑 같은 건 이미지가
     제각각/없음 → 추상. 이걸 아기가 스스로 구분하는지 봐라.

■ 6. 말 걸어서 확인 (가끔 개입)
   - "바다는 물이다" 라고 말 걸면 → "기억할게" 하고 배워야 한다.
   - "시간은 돈이다" 라고 말 걸면 → 아는 것과 어긋나므로
     비유로 알아듣거나 "농담이야?" 하고 되물어야 한다(그대로 안 믿음).
   - (정보 신뢰성) 아는 것과 어긋나는 걸 자꾸 겪으면 → 바로 안 믿고 '의심'에
     올리고, 반대 증거가 쌓이면 '지금 믿는 것'이 뒤집힌다(확정 안 만듦).
     한 곳만 말한 건 확신이 낮고, 여러 곳에서 겪을수록 확신이 오른다
     (단 '여러 곳=사실'은 아님 — 반대가 나오면 다시 흔들린다).

■ 7. 화면 7·8단계
   - 7 통합·자율: 자기평가(확실/배우는중/궁금/의심), 계획.
   - 8 마음·사회: 좋아하는 것, 비유, 상대가 말한 것 기억.
   - (심화됨) 이제 아기가 스스로:
     · 비유를 '먼저 만든다' — 분류는 다른데 하는 일이 겹치는 짝을 스스로 찾아
       "시간은 돈 같은 거네"처럼 내놓는다(누가 안 알려줘도).
     · 전이 추측에 '확신 강도'를 붙인다 — 형제 몇 개가 그 관계를 가졌는지 세서
       "거의 그럴 거야" vs "그럴 수도".
     · 상대 마음을 추측한다 — 자꾸 묻는 걸 보고 "상대는 이걸 모르나 봐".
     · 공감한다 — 내가 겪은 기분으로 상대 감정에 공감(안 겪은 건 "잘 몰라").
   - 이 심화들은 이제 화면 8단계 카드로도 보인다(이번에 추가):
     🎨 스스로 만든 비유 / 🧠 상대 마음 추측 / 💗 공감.
     겪음이 아직 없으면 "아직 없어요"가 정상 시작이다.
     (POST /social 응답의 invented_metaphors·partner_mind·empathy 로도 확인 가능)

■ 8. 껐다 켜기 (재시작)
   - 서버 껐다 python server.py 다시 → 에러 없이 켜지고,
     나이·아는 단어가 이어져야 한다.
   - 예전엔 재시작하면 에러(AttributeError) 났음 → 고침.


■ 9. VirusTotal 검사 켜기(선택)
   - config.py 의 VIRUSTOTAL_API_KEY 에 무료 키를 넣으면,
     사이트 열기 전에 VirusTotal로도 검사한다(정적 필터 통과분만).
   - 무료 키: virustotal.com 가입 후 이름 메뉴 > API key.
   - 로그에 "VirusTotal 위험(악성 N)" 이 뜨면 그 사이트를 막은 것.
   - 키 없어도 됨 — 그러면 기존 정적 필터만 동작.

■ 10. 잘못된 정보 걸러내는지 (교차검증·역전)
   - 자동 성장으로 여러 개를 조사시킨 뒤, 같은 것을 여러 사이트에서
     본 관계일수록 확신이 높게 잡히는지 봐라(한 곳만 본 건 낮음).
   - 광고·페이월 문장(로그인/구독/쿠키동의)이 학습 내용에 안 섞이는지 봐라.
   - 아는 것과 반대되는 정보를 겪었을 때, 바로 안 믿고 '의심'에 올렸다가
     반대 증거가 쌓이면 '지금 믿는 것'이 바뀌는지 봐라(확정 안 만듦).
   - 이건 정답표 대조가 아니라 '겪은 증거'로 계속 재평가하는 방식이다.
   * 로직 자체는 확인됐지만, 진짜 인터넷에서 20곳 읽으며 실제로 축적·역전되는 건
     네 컴퓨터에서만 확인된다.

■ 11. 이번 추가분 확인 (화면·발화·봇차단·OCR)
   - 6단계 관계망: 관계마다 [확신 N]이 붙는지. 여러 곳에서 본 관계일수록
     높고, 한 곳만 본 건 낮아야 맞다.
   - 8단계: 🎨 스스로 만든 비유 / 🧠 상대 마음 추측 / 💗 공감 카드가 뜨는지.
     겪음이 쌓이기 전엔 "아직 없어요"가 정상.
   - 검색 중 패널에 "🖱 동의/쿠키 배너 닫음"이 뜨는지. 결과가 안 뜨면
     "⚠️ … 결과가 안 떠요(캡차/동의 화면일 수 있음)"가 뜨고 화면이 남는지 —
     그 캡처를 나에게 보내라(봇차단인지 다른 문제인지 판별용).
   - 검색을 여러 번 시켜보고, 0건이던 엔진이 실황 로그 '엔진 합치는 중'의
     순서에서 뒤로 밀리는지(껐다 켜면 초기화되는 게 정상).
   - 💬에서 🔊 켜고 물어보면: 답이 문장 조각으로 끊어 읽히는지,
     말하는 중 새로 물으면 이전 발화가 멈추는지.
   - OCR(tesseract) 안 깔린 컴퓨터라면: 검색 때 "⚠️ OCR 라이브러리 없음 …"이
     '딱 한 번' 뜨고, HTML 본문 읽기로 대체해 계속 가는지.
