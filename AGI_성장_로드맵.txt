  AGI 성장 로드맵
  아이에서 성인까지 — 사전 주입이 아니라 '진짜 겪어서' 배우는 순서
════════════════════════════════════════════════════════════

핵심 원칙:
  · 사전을 통째로 머리에 넣지 않는다. 아기는 백지(0)에서 시작한다.
  · '진짜로 보고(이미지) → 이름을 알아내고 → 여러 번 겪어' 배운다.
  · 사전·검색·번역·이미지는 부모/도구다 (물어보면 알려줌).
  · 세상 = 인터넷. 사전은 걸음마용 시작점. 아이는 사람처럼 브라우저로 찾는다.
  · 좋아함·추상·비유 같은 것도 규칙 딱지가 아니라 '겪은 사실'에서 나온다.

표시:  [O] 했음   [△] 기초 수준/네 컴퓨터 검증 필요   [X] 잘못(고쳐야)   [ ] 아직

 1부. 유아기 — 지각과 첫 단어
──────────────────────────────────────────────
[O] 0~4. 백지·패턴·기분행동·인과·시각·청각
[O] 5. 단어 배우기 (고침) — 백지에서, 진짜 보고(이미지), 이름 듣고,
       여러 번(3회+) 겪어야 확실. stats는 확실한 것만 셈.
       진짜 이미지 학습은 네 컴퓨터(인터넷)에서 확인★
[O] 6. 속성도 겪어서 — 여러 번(2회+) 함께 겪은 속성만 안다.

[O] 9. 의미가 맞는 문장 — 아무 말 조합이 아니라 '확실히 아는 것'으로 문장.
[O] 14. 번역 잇기 — 미리 안 잇는다. 두 언어 다 겪어 확실할 때 스스로 잇는다.

──────────────────────────────────────────────
 4부. 호기심 — 인터넷에서 사람처럼 배우기
──────────────────────────────────────────────
[O] 19~24. 모르는 것 알아채기·스스로 찾기·꼬리물기·브라우저 운전(사람처럼)
[△] 25. 진짜 인터넷 학습 — 사람 방식(진짜 브라우저 창을 띄워 검색창에 치고,
        마우스·스크롤 하며 사이트를 '한 개씩 순서대로' 열어 읽기). 봇처럼 API 긁기 아님.
        실황·브라우저 화면이 오른쪽 패널에 뜸.
        (개선) 여러 검색엔진(구글·빙·덕덕고·네이버) 결과를 전부 합침(중복 제거),
        한 번에 최대 20곳. 브라우저는 한 번만 켜고 탭 교체(사이트마다 안 껐다 켬),
        봇 감지 핵심은 유지하되 굼뜬 대기만 줄여 빠르게(SPEED). VT 검사도 그
        브라우저 재사용. 광고·페이월은 학습 전 제외.
        · 쓰려면: python -m playwright install chromium (브라우저 본체) 필요.
        · (봇차단 대응 추가) 쿠키/동의 배너는 사람처럼 '동의' 버튼을 눌러 닫고,
          결과가 실제로 떴는지 확인해 안 떴으면 "⚠️ 캡차/동의 화면일 수 있음"으로
          정직히 표시(+그 화면 캡처를 패널에 남김). 멈춤 시간은 사람처럼
          들쭉날쭉(가끔 길게). 결과 잘 주는 엔진부터 먼저 가고 0건인 엔진은
          뒤로 미룸(껐다 켜면 초기화).
        · 정직한 한계: 검색엔진이 자동 브라우저를 막을 수 있음(동의/캡차).
          그러면 결과 0곳 → 패널에 "⚠️ 검색 결과를 못 가져왔어요"로 정직히 표시.
          위 대응을 넣었어도 이 봇 차단은 완전히 해결되진 않음. 네 컴퓨터에서 확인★

──────────────────────────────────────────────
 6부. 진짜 이해
──────────────────────────────────────────────
[△] 31. 의미로 — 개념 = 이름·모습·속성·하는일·관계·다른나라말 묶음.
[O] 32. 개념 관계망 (부분-전체·가짐·반대·인과·시기)
[O] 32-1. 정보 신뢰성 (잘못된 정보를 안 삼키게, 계속 겪어서 걸러냄) — 정답표 아님.
        · 관계마다 '증거'를 저장(본 횟수·반대 본 횟수·어느 사이트). 확신도는
          저장 안 하고 볼 때마다 재계산(고정 임계값 없음). '몇 곳=사실' 아님.
        · 광고·페이월 껍데기는 학습 전에 버림(_is_junk_text).
        · 어긋나는 정보는 바로 안 믿고 '의심'에 올림. 반대 증거가 쌓이면
          '지금 믿는 것'이 뒤집힘(예: 펭귄 어류→조류). 확정 상태 안 만듦.
        · 확신도는 화면 6단계 관계망에 [확신 N]으로 보임(이번에 표시 추가).
        · 로직 검증됨. 진짜 인터넷 축적·역전은 네 컴퓨터에서 확인★
[O] 33. 추상 — 규칙 딱지 없이 아이가 스스로:
        볼 때마다 모습 일정 → 실체 있음(구체) / 볼 때마다 제각각 → 추상
        본 적 없이 말·글로만 → 추상. 재시작해도 판단 유지(겪음 장부 저장).
        진짜 이미지로의 발견은 네 컴퓨터에서 확인★
[O] 34. 비유 — 분류가 어긋나도 같이 쓰는 말이 겹치면 비유로 알아듣는다
        ("시간은 돈이다"). (심화) 이제 스스로도 만든다 — 아는 개념들을 훑어
        '분류는 다른데 하는 일(동사)이 겹치는 짝'을 먼저 찾아 은유로 내놓는다
        (invent_metaphor). 겪은 연어에서만 나옴(규칙 딱지 아님).
        화면 8단계 '🎨 스스로 만든 비유' 카드로 보임(이번에 추가).

──────────────────────────────────────────────
 7부. 능력 통합
──────────────────────────────────────────────
[O] 35. 말한 걸 추론에, 추론한 걸 말에 — 사람이 문장으로 말하면 배우고,
        답할 땐 아는 분류·관계를 보탠다.
[△] 36. 처음 확실히 알게 된 말을 스스로 말해봄(실황 로그에 뜸).
[O] 37. 전이 — 같은 부류(형제) 개념의 관계를 새 단어에 '추측'으로 옮겨봄.
        (심화) 형제 몇 개가 그 관계를 공유하는지 세서 '추측의 확신 강도'를 붙인다
        ("거의 그럴 거야" vs "그럴 수도"). transfer_guess.

 8부. 자율성
──────────────────────────────────────────────
[△] 38. 스스로 목표
[△] 39. 계획 — 궁금한 것을 궁금한 순서대로 계획해서 알아본다.
[O] 40. 자기평가 — 확실히 아는 것/배우는 중/궁금/의심을 스스로 센다(화면 7단계).
[△] 41. 방향 — 계획 순서가 호기심의 방향이 된다.

──────────────────────────────────────────────
 9부. 사회성과 대화
──────────────────────────────────────────────
[△] 42. 진짜 대화 — 모르면 되묻고, 주제를 기억해 잇는다.
[O] 43. 상대 기억 — 상대가 말한 걸 기억("이거 자주 물어보네").
        (심화) 빈도에서 상대 마음을 추측 — "자꾸 묻는 걸 보니 상대는 이걸
        모르나 봐"(확신 아님). guess_partner_mind.
        화면 8단계 '🧠 상대 마음 추측' 카드로 보임(이번에 추가).
[O] 44. 공감 — '감정'이라고 배운 것에 한해, 제 기분 경험으로 공감.
        (심화) 상대 감정에 내 겪은 기분으로 공감하되, 안 겪어본 건 지어내지 않고
        "잘 몰라". empathize.
        화면 8단계 '💗 공감' 카드로 보임(이번에 추가).
[△] 45. 거짓·농담 — 아는 것과 어긋나면 그대로 안 믿고 되묻고 의심에 기록.

──────────────────────────────────────────────
[△] 46. 새로움 — 가설 만들기 수준.
[△] 47. 가치 — 좋아/싫어가 규칙이 아니라 '겪을 때 기분'에서 나온다.
[△] 48. 메타인지 — 확신/추측 구분·의심·자기평가.
[△] 49. 이어지는 계획 — 계획·궁금함·겪음 장부가 저장돼 껐다 켜도 이어진다.
[△] 50. 실시간 대화(인간 속도 발성) — (기초) 답을 통째로 읽던 것을
        '문장 조각으로 나눠 순차 발화'(스트리밍)로 바꿈(브라우저 목소리 그대로).
        새 질문하면 이전 발화는 멈춤. 답이 만들어지는 대로 흘려보내는 입구
        (_speakStreamPush)도 열어둠 — 단 서버가 답을 조각으로 주는 건 아직 아님.
        진짜 발화·끊김 없음은 네 컴퓨터에서 확인★.
        음성 데이터(목소리)로 말하기는 나중에 하기로 함.
